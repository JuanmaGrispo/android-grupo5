2. SERVICIO API / REPOSITORIO
================================================================================

2.1. Crear servicio de API para obtener el historial
------------------------------------------------------
Crear un archivo de servicio (ej: attendanceService.ts o api/attendance.ts):

import axios from 'axios'; // o fetch, o tu cliente HTTP preferido

const API_BASE_URL = 'https://tu-api.com/api/v1'; // Ajustar según tu backend

export const attendanceService = {
  /**
   * Obtiene el historial de asistencias del usuario autenticado
   * @param token - Token de autenticación JWT
   * @returns Promise con lista de AttendanceDto
   */
  getMyAttendance: async (token: string): Promise<AttendanceDto[]> => {
    const response = await axios.get(`${API_BASE_URL}/attendance/me`, {
      headers: {
        'Authorization': `Bearer ${token}`
      }
    });
    return response.data;
  }
};

NOTA: El endpoint es: GET /api/v1/attendance/me
      Requiere header: Authorization: Bearer {token}

3. COMPONENTE REACT: HistoryPage / HistoryComponent
================================================================================

3.1. Estructura del componente
-------------------------------
Crear un componente funcional con React Hooks:

import React, { useState, useEffect } from 'react';
import { attendanceService } from '../services/attendanceService';
import { useAuth } from '../hooks/useAuth'; // o tu sistema de autenticación

const HistoryPage: React.FC = () => {
  // Estados
  const [attendanceData, setAttendanceData] = useState<AttendanceDto[]>([]);
  const [filteredData, setFilteredData] = useState<AttendanceDto[]>([]);
  const [loading, setLoading] = useState<boolean>(true);
  const [error, setError] = useState<string | null>(null);
  
  // Estados para filtros de fecha
  const [startDate, setStartDate] = useState<Date | null>(null);
  const [endDate, setEndDate] = useState<Date | null>(null);
  const [isFilterActive, setIsFilterActive] = useState<boolean>(false);

  // Obtener token de autenticación (ajustar según tu sistema)
  const { token } = useAuth();

  // Cargar historial al montar el componente
  useEffect(() => {
    loadHistory();
  }, []);

  // Función para cargar el historial
  const loadHistory = async () => {
    if (!token) {
      setError('Sesión no iniciada. Iniciá sesión.');
      setLoading(false);
      return;
    }

    setLoading(true);
    setError(null);

    try {
      const data = await attendanceService.getMyAttendance(token);
      setAttendanceData(data);
      setFilteredData(data);
    } catch (err: any) {
      if (err.response?.status === 401) {
        setError('Sesión expirada. Iniciá sesión de nuevo.');
      } else {
        setError(`No se pudo cargar el historial: ${err.message}`);
      }
    } finally {
      setLoading(false);
    }
  };

  // ... resto de funciones (ver secciones siguientes)
};

4.2. Función para aplicar filtro
----------------------------------
const applyDateFilter = () => {
  if (!startDate || !endDate) return;
  if (startDate > endDate) {
    alert('La fecha de inicio debe ser anterior a la fecha de fin');
    return;
  }

  setIsFilterActive(true);
  const filtered = filterByDateRange(attendanceData, startDate, endDate);
  setFilteredData(filtered);
};

4.3. Función para limpiar filtro
---------------------------------
const clearDateFilter = () => {
  setIsFilterActive(false);
  setStartDate(null);
  setEndDate(null);
  setFilteredData(attendanceData);
};

4.4. Función de filtrado
------------------------
const filterByDateRange = (
  data: AttendanceDto[], 
  start: Date, 
  end: Date
): AttendanceDto[] => {
  return data.filter(dto => {
    if (!dto.session?.startAt) return false;
    
    const sessionDate = parseDate(dto.session.startAt);
    if (!sessionDate) return false;
    
    // Comparar solo las fechas (sin hora)
    const sessionDateOnly = new Date(
      sessionDate.getFullYear(),
      sessionDate.getMonth(),
      sessionDate.getDate()
    );
    const startOnly = new Date(
      start.getFullYear(),
      start.getMonth(),
      start.getDate()
    );
    const endOnly = new Date(
      end.getFullYear(),
      end.getMonth(),
      end.getDate()
    );
    
    return sessionDateOnly >= startOnly && sessionDateOnly <= endOnly;
  });
};

4.5. Función para parsear fechas ISO
-------------------------------------
const parseDate = (dateString: string): Date | null => {
  try {
    // Formato esperado: "2025-09-27T11:30:00.000Z"
    return new Date(dateString);
  } catch (e) {
    return null;
  }
};

4.6. Validación del botón "Aplicar Filtro"
-------------------------------------------
const canApplyFilter = startDate !== null && 
                       endDate !== null && 
                       startDate <= endDate;

<button 
  onClick={applyDateFilter}
  disabled={!canApplyFilter}
>
  Aplicar Filtro
</button>

<button onClick={clearDateFilter}>
  Limpiar
</button>

5.1. Transformar datos a formato UI
------------------------------------
Crear una función que transforme AttendanceDto[] a items renderizables:

interface HistoryItem {
  title: string;
  subtitle: string;
  locationName: string;
  durationMin: number;
  attended: boolean;
}

const transformToHistoryItems = (data: AttendanceDto[]): HistoryItem[] => {
  return data
    .filter(dto => dto.session !== null)
    .map(dto => {
      const session = dto.session!;
      const classRef = session.classRef;
      
      const title = classRef?.title || 'Clase';
      const dateUi = formatDateForUI(session.startAt);
      const teacher = classRef?.instructorName || '';
      const locationName = classRef?.locationName || '';
      const durationMin = session.durationMin || 0;
      
      // Este endpoint representa asistencias efectivas -> siempre "Asistida"
      const attended = true;
      
      const subtitle = `${dateUi}${durationMin > 0 ? ` • ${durationMin} min` : ''}`;
      
      return {
        title,
        subtitle,
        locationName,
        durationMin,
        attended
      };
    });
};

5.2. Función para formatear fechas
-----------------------------------
const formatDateForUI = (isoDate: string): string => {
  if (!isoDate) return '';
  
  try {
    const date = new Date(isoDate);
    // Formato: "dd/MM - HH:mm hs"
    const day = String(date.getDate()).padStart(2, '0');
    const month = String(date.getMonth() + 1).padStart(2, '0');
    const hours = String(date.getHours()).padStart(2, '0');
    const minutes = String(date.getMinutes()).padStart(2, '0');
    
    return `${day}/${month} - ${hours}:${minutes} hs`;
  } catch (e) {
    return isoDate;
  }
};

5.5. Función para formatear rango de fechas
--------------------------------------------
const formatDateRange = (start: Date, end: Date): string => {
  const formatDate = (date: Date) => {
    const day = date.getDate();
    const monthNames = ['Ene', 'Feb', 'Mar', 'Abr', 'May', 'Jun', 
                        'Jul', 'Ago', 'Sep', 'Oct', 'Nov', 'Dic'];
    const month = monthNames[date.getMonth()];
    const year = date.getFullYear();
    return `${day} ${month}${date === end ? ` ${year}` : ''}`;
  };
  
  return `${formatDate(start)} - ${formatDate(end)}`;
};

---------------------

----------------------

- Error de red: "Fallo de red: {mensaje}"
- Otros errores: "No se pudo cargar el historial ({código})"

7.3. Estado vacío
-----------------
- Mostrar "Sin historial por ahora." cuando no hay datos

9. CONSIDERACIONES ADICIONALES
================================================================================

9.1. Autenticación
------------------
- Asegurarse de que el token esté disponible antes de hacer la petición
- Manejar la expiración del token (redirigir al login si es necesario)

9.2. Optimizaciones
--------------------
- Considerar usar React.memo para HistoryCard si hay muchas tarjetas
- Implementar paginación si el historial es muy grande
- Usar useMemo para el filtrado si los datos son grandes

9.3. Librerías recomendadas
-----------------------------
- react-datepicker: Para selectores de fecha
- date-fns o dayjs: Para manipulación de fechas (alternativa a funciones nativas)
- axios o fetch: Para peticiones HTTP
- react-query o SWR: Para manejo de estado del servidor (opcional pero recomendado)

9.4. Ejemplo con React Query (opcional)
----------------------------------------
import { useQuery } from 'react-query';

const { data, isLoading, error } = useQuery(
  'attendance-history',
  () => attendanceService.getMyAttendance(token),
  {
    enabled: !!token,
    retry: 1
  }
);
